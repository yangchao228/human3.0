# Human3.0 页面原型与信息架构

## 1. 文档信息

- 文档名称：Human3.0 页面原型与信息架构
- 对应 PRD 版本：v0.1
- 文档日期：2026-03-11
- 目标：把 PRD 拆解到页面、导航、模块和核心交互层，作为前端设计与开发基线

## 2. 设计原则

1. 首页不是内容流，而是当日认知概览。
2. `Daily Brief` 是主入口，内容流是补充入口。
3. 页面层级尽量浅，避免用户在过多页面间跳转。
4. 重要信息先结论后细节，先摘要后原文。
5. 所有页面都要支持围绕“主题、评分、来源、日期”快速收敛。

## 4. 核心用户流

### 4.1 首次启动流

1. 进入仪表盘空状态。
2. 系统提示先添加信息源。
3. 用户进入信息源页，添加 RSS/博客/GitHub 源。
4. 添加完成后触发首次抓取。
5. 系统显示抓取与分析进度。
6. 抓取完成后跳转到今日 Brief。

### 4.2 每日使用流

1. 用户打开系统进入仪表盘或今日 Brief。
2. 查看“今日最重要”和“值得关注”。
3. 对某条内容点开详情。
4. 判断是否阅读原文或加入知识库。
5. 如需深挖，再切换到内容流按标签或来源筛选。

### 4.3 长期沉淀流

1. 用户在 Brief 或内容详情页点击“加入知识库”。
2. 选择知识分类并补充个人备注。
3. 进入知识库查看累计条目。
4. 通过主题、时间和来源回顾历史内容。

### 4.4 系统维护流

1. 管理员进入任务中心查看抓取、分析和日报任务。
2. 对失败任务执行重试。
3. 在设置页调整模型、评分阈值和日报模板。

## 7. 页面原型

### 7.1 仪表盘 `/dashboard`

### 页面目标

提供当日系统运行概览和高价值内容入口，适合作为默认首页。

### 页面模块

1. 顶部欢迎区
2. 今日概览指标卡
3. 今日高优先内容预览
4. 系统任务状态
5. 最近入库知识条目
6. 信息源健康度

### 低保真原型

```text
+----------------------------------------------------------------------------------+
| Dashboard                                                 [Add Source] [Run Now] |
+----------------------------------------------------------------------------------+
| 今日已抓取 42 | 已分析 38 | 高分内容 9 | 今日日报 已生成                          |
+----------------------------------------------------------------------------------+
| 今日重点预览                                                                    |
| 1. OpenAI Agent 架构更新     9.2   AI Agent / Infra        [查看详情] [收藏]     |
| 2. Anthropic Memory 研究     8.4   Memory / Research       [查看详情] [收藏]     |
+--------------------------------------------------+-------------------------------+
| 任务状态                                         | 最近加入知识库                 |
| 抓取任务: 成功 12 / 失败 1                        | - AI Infra 趋势总结            |
| 分析任务: 进行中 3                               | - Agent workflow note          |
| 日报任务: 今日 07:05 完成                        | - 创业信息过滤框架             |
+--------------------------------------------------+-------------------------------+
| 信息源健康度                                                                     |
| RSS 8 正常 | GitHub 3 正常 | Newsletter 2 失败 1                                 |
+----------------------------------------------------------------------------------+
```

### 关键交互

1. 点击高分内容进入内容详情页。
2. 点击指标卡可跳转到对应筛选结果。
3. 点击任务状态可跳转任务中心。
4. 点击信息源异常项可跳转信息源页并带失败筛选。

### 7.2 今日 Brief `/brief/today`

### 页面目标

作为主阅读入口，帮助用户在 5 分钟内完成当日认知输入。

### 页面模块

1. 日期与日报状态
2. 日报摘要头图区
3. 今日最重要
4. 值得关注
5. 工具更新
6. 一个启发
7. 导出与重新生成操作区

### 低保真原型

```text
+----------------------------------------------------------------------------------+
| Human3.0 Daily Brief                                   2026-03-11 [Export] [Regen]|
+----------------------------------------------------------------------------------+
| 今日一句话：AI Infra 正在从模型竞争转向工作流与记忆系统竞争                        |
+----------------------------------------------------------------------------------+
| 1. 今日最重要                                                                    |
| [卡片] 标题 / 评分 / 标签 / 核心观点 / 启发 / 原文 / 加入知识库                    |
| [卡片] 标题 / 评分 / 标签 / 核心观点 / 启发 / 原文 / 加入知识库                    |
+----------------------------------------------------------------------------------+
| 2. 值得关注                                                                      |
| [简版卡片列表]                                                                    |
+----------------------------------------------------------------------------------+
| 3. 工具更新                                                                      |
| [工具类内容列表]                                                                  |
+----------------------------------------------------------------------------------+
| 4. 一个启发                                                                       |
| [一段编辑后的 insight 卡片]                                                       |
+----------------------------------------------------------------------------------+
```

### 关键交互

1. 支持切换前一天/后一天日报。
2. 支持对条目执行收藏、加入知识库、查看原文。
3. 支持手动重新生成日报。
4. 支持导出 Markdown。

### 7.3 Brief 历史列表 `/brief/history`

### 页面目标

帮助用户快速回看过去日报，按日期检索认知记录。

### 页面模块

1. 日期筛选器
2. 历史日报列表
3. 生成状态标签
4. 快速查看摘要

### 低保真原型

### 7.4 内容流 `/content`

### 页面目标

提供全量内容浏览、搜索和筛选能力，用于深挖而不是替代 Brief。

### 页面模块

1. 搜索框
2. 筛选栏
3. 排序栏
4. 内容列表
5. 右侧快速统计

### 筛选项

1. 主题标签
2. 评分区间
3. 来源类型
4. 具体来源
5. 日期范围
6. 是否已收藏
7. 分析状态

### 低保真原型

```text
+----------------------------------------------------------------------------------+
| Search: [ AI Agent memory                         ] [Search]                      |
+----------------------------------------------------------------------------------+
| Tags | Score | Source | Date | Saved | Status                           [Reset] |
+----------------------------------------------------------------------------------+
| 排序: 最新 / 评分最高 / 最相关                                                |
+----------------------------------------------------------------------------------+
| [内容卡片]                                                                       |
| 标题                          9.1                                               |
| 来源 GitHub / 2h ago / AI Agent / Memory                                       |
| 一句话总结                                                                       |
| 核心观点                                                                         |
| [详情] [原文] [加入知识库] [重新分析]                                            |
+----------------------------------------------------------------------------------+
| [内容卡片] ...                                                                   |
+--------------------------------------------------+-------------------------------+
| 统计                                             | 快速筛选建议                  |
| 今日共 42 篇                                     | 高分未读 7                    |
| 7 分以上 12 篇                                   | GitHub 更新 5                 |
| AI Agent 8 篇                                    | 工具类 4                      |
+--------------------------------------------------+-------------------------------+
```

### 关键交互

1. 列表支持保存筛选条件。
2. 点击标签可继续收窄结果。
3. 支持对单篇内容重新分析。

### 7.5 内容详情 `/content/[id]`

### 页面目标

提供单篇内容的完整信息，包括原文元数据、AI 分析结果和收藏沉淀动作。

### 页面模块

1. 标题与元数据区
2. AI 分析摘要卡
3. 原文摘要或正文预览
4. 相关内容推荐
5. 操作区

### 低保真原型

```text
+----------------------------------------------------------------------------------+
| 标题：OpenAI Agent Framework Update                                             |
| 来源 OpenAI Blog | 发布时间 2026-03-11 | 评分 9.2 | 标签 Agent / Infra          |
+----------------------------------------------------------------------------------+
| AI 摘要                                                                          |
| 一句话总结：...                                                                  |
| 核心观点：...                                                                    |
| 关键启发：...                                                                    |
| 评分拆解：相关度 9 / 密度 8 / 原创性 9 / 时效性 10                               |
+----------------------------------------------------------------------------------+
| 正文预览                                                                         |
| ...                                                                              |
+----------------------------------------------------------------------------------+
| [查看原文] [加入知识库] [收藏] [重新分析] [编辑标签]                             |
+--------------------------------------------------+-------------------------------+
| 相关内容                                         | 来源信息                       |
| - Anthropic memory update                        | 源名称 / 抓取时间 / 状态       |
| - Agent infra benchmark                          |                                |
+--------------------------------------------------+-------------------------------+
```

### 关键交互

1. “加入知识库”弹出分类与备注表单。
2. “编辑标签”仅管理员或高级用户可见。
3. “查看原文”新窗口打开。

### 页面目标

管理输入结构，而不是管理内容本身。

### 页面模块

1. 信息源统计卡
2. 信息源列表
3. 新建信息源入口
4. 健康状态与错误信息

### 低保真原型

```text
+----------------------------------------------------------------------------------+
| Sources                                                     [Add Source]         |
+----------------------------------------------------------------------------------+
| 总数 14 | 启用中 12 | 异常 2 | 今日新增内容 42                                     |
+----------------------------------------------------------------------------------+
| 名称              类型      标签              抓取频率    状态        操作         |

```

### 新建/编辑信息源表单

1. 名称
2. 类型
3. URL
4. 默认标签
5. 抓取频率
6. 优先级
7. 是否启用

### 关键交互

1. 新建和编辑优先采用右侧抽屉，不跳新页面。
2. 异常源支持查看最近错误日志。
3. 允许单源立即抓取。
4. 若需要可分享的编辑态，建议使用 `/sources?sourceId=xxx` 形式驱动抽屉。

## 8. 页面状态设计

### 8.1 空状态

1. 仪表盘无数据时，引导用户添加第一个信息源。
2. 今日 Brief 未生成时，显示“先完成抓取与分析”。
3. 知识库为空时，提示从 Brief 或内容详情加入条目。

### 8.2 加载状态

1. 列表页使用骨架屏。
2. 指标卡先展示占位，不阻塞主内容。
3. 日报生成中显示进度与最近更新时间。

### 8.3 错误状态

1. 抓取失败显示到来源级别。
2. AI 分析失败显示到内容级别。
3. 日报失败显示可重试按钮和失败原因。

## 12. 交付建议

### 阶段一：产品线框图

先按本文档把 7 个 P0 页面做成低保真线框图，确认结构和信息优先级。

### 阶段二：前端骨架

基于 `Next.js App Router` 建立路由、Layout、导航、列表页和详情页壳子。

### 阶段三：组件系统

抽离分数徽标、标签、内容卡片、任务卡片、知识条目抽屉等核心组件。

### 阶段四：联调

按 PRD 中的 API 范围逐页对接 FastAPI 后端。
